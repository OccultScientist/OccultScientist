# Toby Kilroy

I’m a software engineer and the founder of [Get Clever](https://getclever.co.uk/). I build and run web platforms, with much of my work behind the scenes in publishing and research.

## What I work on

- **Web applications and APIs.** Laravel and PHP are my main tools for building web platforms. I use Python for data processing, automation and prototypes.
- **AI agents and retrieval.** I connect agents to tools through the Model Context Protocol (MCP) and use retrieval-augmented generation (RAG) to build answers people can trace back to a source.
- **Workflow automation.** I like taking a job someone has to do by hand and making it repeatable. That includes the details that matter on the second run, like knowing what failed, what can be retried and when to ask someone to step in.
